# 배치(lot)별 품질검사 결과 추세 대시보드

AID 해커톤 · ㈜포스포 연계 과제 MVP 시안입니다. 모든 수치는 가상 데이터이고, 검사 항목·규격·점검 포인트는 가설입니다.

- **과제 핵심:** `index.html` LOT 품질 관리도 (lot별 검사 결과 추세, 이탈 예고, LOT 상세)
- **확장:** 이상 신호를 현장 조치까지 잇는 화면 (품질 알림 앱, CCR 콘솔, 현장 작업자 단말)

## 화면

| 파일 | 내용 |
|---|---|
| `start.html` | 시작 화면 (과제 핵심 화면과 확장 화면 입구) |
| `index.html` | **LOT 품질 관리도 대시보드** (색좌표·순도·입도·수분·휘도, 이상 판정, 이탈 예고, LOT 상세, CSV 업로드) |
| `test.html` | 판정 규칙 테스트 시나리오 |
| `live.html` | 휴대폰용 LOT 품질 알림 앱 (이탈 예고 포함) |
| `process.html` | 공정 변수 CCR 콘솔 + 현장 작업자 단말 미리보기 |
| `process.html?role=worker` | 현장 작업자 단말 (휴대폰) |
| `qr.html` | 휴대폰 접속 QR |

## 온라인(GitHub Pages)과 발표 PC의 차이

- 온라인 버전은 어느 네트워크에서든 모든 화면을 볼 수 있습니다.
- CCR 콘솔과 휴대폰 단말이 **실시간으로 주고받는 기능**은 서버가 필요합니다. 발표 PC에서 아래처럼 서버를 띄우고, 같은 Wi-Fi의 휴대폰으로 `http://<PC IP>/w` 에 접속하세요.

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

짧은 주소: `/w` 현장 단말, `/q` 품질 알림, `/c` CCR 콘솔, `/d` 대시보드, `/qr` 접속 QR.

## 주제 적합성 수정 (2026-11-26)

| 파일 | 수정 내용 |
|---|---|
| `start.html` | 품질 관리도를 '과제 핵심' 메인 버튼으로 맨 위에 두고, 나머지는 '확장'으로 묶음. 제목을 과제명으로 변경 |
| `index.html` | 색좌표 CIE x·y 항목 추가 (포스포의 고객 맞춤 색좌표 반영, 규격은 가설) |
| `index.html` | 이탈 예고: 최근 5 lot 추세로 "약 N lot 뒤(날짜) 규격 도달 예상"을 요약에 '예고'로 표시하고 관리도에 예측선·예측 구간 표시 |
| `index.html` | 관리한계 기준 구간 고정: '전체 lot' 선택지 제거, 기준 구간에 이탈 lot이 있으면 경고 |
| `index.html` | LOT 상세: 표의 행이나 관리도 점을 누르면 그 lot의 전 항목 값·규격·관리한계·판정 이유·점검 포인트 표시 |
| `index.html` | 요약과 표가 엇갈려 보이던 문제: 추세·치우침 진행 중(판정 전) lot을 표에 주황 밑줄로 표시, 요약에 "6·7번째 lot부터 주의 판정" 안내, 연달아 나온 이탈은 한 줄로 묶음 |
| `live.html` | 새 알림이 없어도 최근 lot에 예고·주의·이탈 신호가 있으면 상단에 "최근 lot ○○ 신호"로 표시 (전에는 "정상 가동 중"으로 보였음) |

`test.html`의 판정 규칙(관리한계·연속 7점·연속 6점)은 바꾸지 않았습니다.
